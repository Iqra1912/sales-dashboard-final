# Sales Analysis and Reporting System

A full-stack web application designed to help businesses clean, analyze, and visualize sales data through an interactive dashboard.

## 🚀 Features
* **Data Cleaning Pipeline:** Automated handling of missing values and data formatting using Pandas.
* **Interactive Dashboard:** Visual representation of KPIs and sales trends using React and Chart.js.
* **Secure Authentication:** User login and registration with Google OAuth integration.
* **AI Insights:** Automated generation of business insights from uploaded datasets.

## 🛠️ Tech Stack
* **Frontend:** React, Tailwind CSS
* **Backend:** Python (Flask)
* **Database:** SQLite (SQLAlchemy ORM)
* **Data Processing:** Pandas, NumPy
